# Christie_-Akpan_-week2_ -Healthcare-

Stroke Data Analysis Project

Project Overview

This project focuses on analysing a healthcare dataset to identify patterns and factors associated with stroke occurrence. The analysis explores how demographic characteristics, medical conditions and lifestyle factors relate to stroke cases.

The goal is to transform raw healthcare data into meaningful insights that can support better understanding and data-driven decision-making.

Project Objectives

- Analyse the distribution of stroke cases.
- Examine stroke occurrence across different age groups.
- Investigate the relationship between hypertension and stroke.
- Analyse stroke cases based on heart disease.
- Explore stroke occurrence by gender.
- Examine the relationship between smoking status and stroke.
- Identify patterns in average glucose levels and BMI.

Tools Used

- Microsoft Excel: Data cleaning, data understanding and preliminary analysis.
- SQL Server Management Studio (SSMS): Data querying and analysis.
- Microsoft Power BI: Data visualization, dashboard development and reporting.

Data Cleaning and Preparation

The dataset was prepared before analysis. The process included:

- Checking for duplicate records.
- Identifying missing values.
- Examining unknown and unavailable entries.
- Reviewing data types and column formats.
- Creating age groups for easier analysis.
- Categorizing relevant variables for visualization.

Key Analysis Areas

1. Stroke cases by age group.
2. Stroke cases by gender.
3. Stroke cases by hypertension status.
4. Stroke cases by heart disease status.
5. Stroke cases by smoking status.
6. Stroke occurrence and average glucose levels.
7. Stroke distribution across other demographic and health-related factors.

Dashboard

An interactive Power BI dashboard was developed to present the findings using visualizations and key performance indicators (KPIs).

The dashboard helps users explore stroke distribution and compare different health and demographic characteristics.

Key Findings

The analysis revealed differences in stroke occurrence across age groups and health conditions.

- Older age groups recorded a higher proportion of stroke cases.
- Individuals with hypertension showed a higher stroke proportion than those without hypertension.
- Individuals with heart disease also showed a higher proportion of stroke cases.
- Stroke occurrence varied across gender and smoking-status categories.

These findings describe associations in the dataset and do not establish that any factor directly causes stroke.

Conclusion

This project demonstrates how Excel, SQL and Power BI can be used together to clean, analyse and visualize healthcare data.

It also strengthened my practical skills in data preparation, SQL querying, exploratory data analysis, dashboard development and communicating insights.
